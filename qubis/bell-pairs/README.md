# Bell pairs, with a Qubi

Qubi is a physical model qubit from [Qolour](https://www.qolour.com/). The hands-on Bell pairs activity for Lab 001 is Qolour's own lesson:

[Bell Pairs, Qubi Educator Course](https://www.qolour.com/educator-course/bell-pairs)

That page was opened on 18 November 2026. It is the lesson. This folder does not repeat it, and it does not invent buttons, dials, or app screens. Follow the controls Qolour actually provides. The physical preflight also includes the battery, Bluetooth connection, orientation, and pair activity described in Stop 1 of the beginner notebook, with the quickstart as the authority for the taps. If the page is unavailable, use Stop 1 of the beginner notebook, section 08 of the advanced notebook, and the worksheet. Those prompts still work with a verbal walk-through.

## How this fits the lab

1. See the pattern with the physical model, or with the prompts if you do not have a kit.
2. Write what you observed before you see the vector.
3. Build the same state in Qiskit. Start with [the beginner notebook](../../labs/01_entanglement/entanglement_beginner.ipynb). The [advanced notebook](../../labs/01_entanglement/entanglement_hands_to_hardware.ipynb) keeps the original mathematics.
4. Treat an IBM quantum processor as a third, optional step, after the local simulation makes sense.

Qubi is the visualization. Qiskit is the representation. IBM hardware is the execution. They are three different objects. A result from one of them is not automatically a result from the others.
