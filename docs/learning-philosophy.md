# Learning philosophy

Quantum for the Qulture teaches by a fixed order. The order is the point.

See it. Understand it. Map it. Code it. Run it. Measure it. Interpret it. Find your pathway.

Seeing comes first so the learner has something to point at. Understanding comes next so the name has a definition. Mapping puts the definition on paper before a framework hides the steps. Code is the map written in Qiskit. A run produces a number. Measurement says which question that number answers. Interpretation says what the number does not prove. The pathway is a next step a person could actually take, including a next step outside quantum computing.

## The lesson pattern

Every major section should be able to answer six questions in this order.

1. What are we doing?
2. Why are we doing it?
3. How does it work?
4. What happened?
5. What does it mean?
6. Where can I go next?

A section that cannot yet answer "what happened" is not finished. A section that answers "what does it mean" with a slogan is not finished either.

## How new words enter

Introduce one idea, give it a definition, then use it. Do not place a pile of undefined nouns in a single paragraph. If a later lab needs a term, leave it for that lab. Lab 001 names the Bloch sphere and then sets it aside. Lab 001 names the other Bell states and does not build them.

Advanced mathematics is not a prerequisite for the first lab. Vectors, addition, and a square root are. The lab shows each vector it uses.

## Encouragement

Encourage a learner by telling them which step they just completed and which step is next. Skip exaggerated claims. Entanglement is interesting because the joint state is precise, not because a qubit sends a message.

## Callouts

Use a callout only when the learner should stop and do something. The allowed labels are:

- PAUSE HERE. Stop and answer before you read on or run the cell.
- TRY THIS. A small change with a predicted effect.
- CHECK YOUR UNDERSTANDING. A question whose answer was already earned by the section.
- FIND IT IN THE DOCS. An official page, and what to look for on it.
- QULTURE CHECK. A moment to connect the calculation to the learner's own path. Use it rarely.

## What we will not say

A computational-basis histogram of a Bell state is a correlation. It is not, by itself, a demonstration of Bell nonlocality. That demonstration is a later lab. A local simulator does not become a quantum computer by using quantum words. A finished lab does not make someone job-ready. [career-pathways.md](career-pathways.md) says that in more detail.

## Culture

Quantum Global Group describes its place as the connection in the middle of the quantum ecosystem: the equals sign between communities, skills, and tools. In a lab, that equals sign is a claim you can check. The state you meant, the state the circuit prepared, and the counts you measured either agree within the limits you can explain, or they do not. The work is to say which.
