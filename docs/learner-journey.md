# Learner journey

This is a map of the path. It is not an application. Nothing on this page collects an answer, stores an email, or unlocks a notebook.

A person can enter at the first stage and stop wherever their question is answered. Lab 001 covers the middle of the path in one sitting: start learning, code it, run it locally, and interpret it.

## The stages

### Discover

The person meets the subject through the Quantum Global Group website, a conversation, a class, or this repository. The website is a separate property: [https://www.quantumglobalgroup.io/](https://www.quantumglobalgroup.io/).

### Find my path

They ask where they might fit. The Quantum Career Navigator lives on the website, not in this repository. The introductory role map we do publish is [career-pathways.md](career-pathways.md).

### Check my readiness

They compare what they already know with the prerequisites of the next lab. For Lab 001 that is arithmetic, the idea of a vector, and enough Python to run a notebook. The worksheet opens with that check.

### Start learning

They read [getting-started.md](getting-started.md) and open Lab 001. The notebook is public. Membership in the learning community is an invitation, not a gate.

### Code it

They build the circuit themselves and compare it with the mathematical state from the previous section.

### Run it

Level 1 is reading and predicting. Level 2 is the local sampler, which needs no IBM account. Level 3 is an optional job on IBM Quantum hardware after access is approved. The levels are defined in [learning-pathway.md](learning-pathway.md).

### Interpret it

They separate the ideal state, the finite sample, and, if they have one, a hardware sample. They write what is still missing.

### Build something

A later lab, a small variation of this circuit, or a project of their own. This repository does not yet host a project gallery.

### Explore opportunities

Roles, further study, and the IBM certification path as one optional credential. Lab 001 is not that credential. See [certification-journey.md](certification-journey.md) and [career-pathways.md](career-pathways.md).

## What a community session adds

When the founder publishes the community link, a guided session can follow this order:

1. Watch.
2. Qubi activity.
3. Open the notebook.
4. Run locally.
5. Request QPU access, if the learner wants hardware and a seat is available.
6. Run on hardware, one deliberate job.
7. Share results.

The notebook remains available to anyone who never joins that session. Video, the physical Qubi demonstration, discussion, hardware onboarding, and extra preparation are the reasons to join. The community link will be added when the founder supplies it. This page does not guess a URL.

## Readiness for hardware

Wanting a hardware plot is not the same as needing one. The questions an administrator should ask, and the seat states, are policy in [qpu-access.md](qpu-access.md). This journey page does not record who asked.
